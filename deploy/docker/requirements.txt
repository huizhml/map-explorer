# and against the experimental 101-band stack (2026-10-28). titiler.core 2.4 /
# rio-tiler 9.4 import and serve tiles with it.
# After the first successful build, `pip freeze` inside the container and pin
# the rest too, so a reviewer six months from now gets the same stack.
